Automatic Type Inference Rules

  • Explicit declarations always take priority. The compiler never silently overrides a declared type.
  • Whole numbers: Inferred as int (e.g. x = 10).
  • Decimal numbers: Inferred as float / double (e.g. price = 25.75).
  • Single characters: Inferred as char (e.g. grade = 'A').
  • Double-quoted text: Inferred as string (e.g. name = "Prachi").
  • Booleans: Inferred as bool (e.g. isPassed = true).
